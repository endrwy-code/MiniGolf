# Working papers

These are the raw outputs of the agent work behind docs 13, 14 and 22 (26–27 Nov, done in a local session because the videos were too big to upload). They were converted to Markdown with local file paths removed, and are otherwise unedited. They're kept so a later session can check the evidence, reuse the ideas that didn't make the cut, and see why the review changed things, without redoing the work.

**The numbered docs win.** Where a working paper and `13-kulnari-benchmark.md` or `14-new-york-iteration-1.md` disagree, the doc is right: it was edited, fact-checked and, for doc 14, corrected by the review. Don't quote these papers to the team as findings. Go to the doc, or check the claim first.

## How doc 14 was made

1. Two designers worked independently from the same brief (the Kulnari library, the research, docs 10–12) with different angles: A to push the gimmicks, B to stay buildable.
2. A synthesis kept design A's ten holes and took design B's choice of The Subway as the prototype. It isn't kept here: doc 14 replaces it.
3. A reviewer tried to break the synthesis. It found physics and geometry errors in six holes (for example, the hole 3 loop floor couldn't slope the way the numbers said, and hole 1's plinko board left no room for its trough), plus unrealistic carpenter-days.
4. A writer folded every must-fix into doc 14, and the should-fix items stayed open (S1–S12).

**Hole numbers differ.** Design A's numbering is the one doc 14 uses. Design B kept doc 10's numbering, so its hole 5 is The Subway, which is doc 14's hole 3.

**Design A and B still contain the errors the review found.** Check any number against doc 14 before you reuse it.
